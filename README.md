# IFI7386 Group 2 — Ticket guidance

Group repository: https://github.com/victimp3/group-2-work

The runnable Group 2 application is at the repository root: `host/`,
`ticket/` and `ticket_serial/`. The previously uploaded course materials in
`ifi7386-interactive-systems-main/` are preserved unchanged as a reference.

Use Node.js >=18, with no dependency installation:

```sh
node --test host/test.js
node host/server.js
```

Open http://localhost:3000. The Pi group hotspot is IFI7386-G2, OPEN,
with server address http://10.42.0.1:3000. The mapping contains sample UIDs;
actual cards and Pi hardware still need verification.

adapted for Group 2 with AI assistance.
